# Mathematical review

The independent check expands every target swap to one binary context and counts disagreement against all inputs. An unrestricted majority realizes the minimum minority count at each context. The restricted rule must agree on both members of every fiber of an input parent set. With nonzero visible bits, each completion strictly prefers one. On the all-zero visible setting, the two output costs are $t-1$ and $t+1$. The unique restricted rule is the original table. This also handles every smaller parent set contained in it.

The unrestricted cost is $t$. Each input differs from a distinct input at exactly two unit contexts, so the best restricted cost is $2(t-1)$. The general upper bound counts ordered pairs of votes, including ties and unanimous contexts, and averages over feasible original tables. Internally reviewed, not peer reviewed.
