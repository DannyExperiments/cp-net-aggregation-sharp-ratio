# Claim scope and limitations

- The exact ratio holds for $t\ge3$ explicit complete strict binary CPTs, local swap disagreement at one target attribute, equal input weights, and positive unrestricted optimum. The upper-bound inequality also handles zero optimum.
- Algorithm 1 permits parent sets contained in an input's parent set. Each least-cost table on the witness has exactly one of the original parent sets and reproduces its original rule.
- The number 2 is a supremum over input counts. At each fixed $t$ the sharp bound is $2-2/t$. The upper bound is an application of the standard best-input averaging argument.
- The earlier $4/3$ theorem for indegree-at-most-one CPTs applies to a separate input restriction. The four-input obstruction needs three relevant parents per input.
- The result concerns Algorithm 1. Other approximation algorithms and aggregation objectives fall outside its scope. The unrestricted full-OR table in this family is only twice as large as each input table.
- The partial Lean certificate checks four-input arithmetic and one general natural-number inequality. The paper gives the all-$t$ theorem and its connection to the source algorithm. [Proof](paper/manuscript.pdf) · [Prior work](audits/public_safe_reports/LITERATURE_AUDIT.md)
