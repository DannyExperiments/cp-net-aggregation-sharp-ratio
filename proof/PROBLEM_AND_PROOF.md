# Problem and proof

In Ali, Yang and Zilles's Algorithm 1, a candidate for the target attribute can use any subset of one input parent set. For each candidate set, the algorithm minimizes disagreements with all input CPTs, pooling votes from contexts that have the same visible parent settings. The unrestricted optimum may choose any parent set. Each assignment to the other binary attributes contributes one target-attribute swap. [Published definition and question](https://ojs.aaai.org/index.php/AAAI/article/download/28911/29733#page=5)

At each context let $k$ be the minority count among $t$ input votes, allowing ties. The unrestricted majority pays $k$, while the sum of the costs of using the $t$ inputs as candidates is $2k(t-k)$. For $k>0$ this is at most $2(t-1)k$. With $k=0$ both counts vanish. Every input is itself a feasible candidate. Averaging proves the upper bound $(2-2/t)\operatorname{OPT}$. This is the best-input argument for the current binary model. [Endriss and Grandi, Theorem 9](https://cdn.aaai.org/ojs/8798/8798-13-12326-1-2-20201228.pdf#page=4)

For sharpness, take $t\ge3$ inputs on $t$ other binary attributes. The $i$-th table is the OR of the bits except $X_i$, uses precisely those $t-1$ parents, and lists all $2^{t-1}$ parent settings. Only singleton contexts split the votes, with a single zero vote each. Thus full OR has optimum cost $t$. Fixing the $i$-th input parent set pairs every context with its flip in $X_i$. Both contexts in any pair with nonzero visible bits strictly favor one. The zero visible pair is $(0^t,e_i)$, with costs $t-1$ for output 0 and $t+1$ for output 1. The optimization uniquely recovers the input rule. Subsets do not lower cost because they are also constant on those pairs.

The restricted rule disagrees with every other input on precisely two singleton contexts, for total cost $2(t-1)$. Hence the exact ratio is $2-2/t$. The positive-optimum condition makes the ratio well-defined. At $t=4$ the ratio is $3/2>4/3$. Identical parentless rules at the other attributes embed the witness into acyclic CP-nets.

The singleton subprofile is the bit complement of Endriss and Grandi's unit-vector profile. The new step is its realization with overlapping parent sets and unanimous contexts that prevent any re-optimization from improving a candidate.
